# Платформа для размещения объявлений (Avito Clone)

Фуллстек-приложение для публикации и управления бесплатными объявлениями. Разработано в рамках дипломного проекта.
Приложение предоставляет REST API, которое полностью соответствует предоставленной OpenAPI спецификации, и работает в связке с готовым React-фронтендом.

## Команда проекта
* **Ярослав Угольников** — Backend-разработчик 

## Реализованный функционал
* **Пользователи:** Регистрация, авторизация (Spring Security), просмотр и редактирование профиля, смена пароля, загрузка аватара.
* **Объявления:** CRUD-операции с объявлениями. Просмотр доступен всем, создание/редактирование/удаление — только авторизованным пользователям.
* **Комментарии:** Добавление, изменение и удаление комментариев под объявлениями.
* **Изображения:** Загрузка и хранение файлов изображений в базе данных (LOB) с последующей отдачей на фронтенд.
* **Безопасность:** Разделение ролей (`USER`, `ADMIN`). Пользователь может изменять только свои данные. Администратор имеет полные права на модерацию контента.

## Стек технологий
* **Язык:** Java 17+
* **Фреймворк:** Spring Boot 3 (Web, Security, Data JPA)
* **База данных:** PostgreSQL
* **Миграции БД:** Liquibase
* **Маппинг:** MapStruct / Ручные мапперы
* **Документация API:** Swagger / Springdoc OpenAPI

## Структура БД

* **Схема данных управляется Liquibase и содержит следующие таблицы:**

* **users** — данные пользователей и их роли.

* **ads** — объявления, привязанные к пользователям.

* **comments** — комментарии, привязанные к объявлениям и авторам.

* **images** — хранилище бинарных данных изображений.
## Запуск проекта
1. Склонируйте репозиторий.
2. Убедитесь, что у вас запущен сервер PostgreSQL.
3. В файле `application.properties` укажите ваши данные для подключения к БД (`url`, `username`, `password`).
4. Запустите приложение. Liquibase автоматически накатит схему базы данных.
5. Swagger UI будет доступен по адресу: `http://localhost:8080/swagger-ui/index.html`
